# Student Management System

A Java-based console application for managing student records.

## Features

- Add a student
- View all students
- Search for a student
- Update student details
- Delete a student
- Prevent duplicate student IDs
- Validate student marks
- Store student data using file handling

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Git
- GitHub
- Eclipse IDE

## How to Run

1. Open the project in Eclipse.
2. Open `Main.java`.
3. Run the program.
4. Select an option from the menu.
5. Enter the required student details.

## Project Menu

1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Update Student
6. Exit
